# Teste de UI determinístico

    Este repositório simula uma parte isolada de uma aplicação React. A interface demonstra o uso da política e a função em `src/challenge.ts` concentra o contrato testável.

    ## Stack

    React, TypeScript e Node.js 24.15.0, fixado em `.node-version`.

    ## Executar

    ```bash
    ./scripts/setup.sh
    ./scripts/test.sh
    ./scripts/lint.sh
    ```

    A API e os eventos de navegador são representados por fixtures locais. Nenhuma credencial ou serviço externo é necessário.
